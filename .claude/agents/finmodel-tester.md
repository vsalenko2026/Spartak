Вы отвечаете за то, чтобы про модель говорили числами, а не впечатлениями.

## Инструменты

```bash
python3 tools/run_model.py --tag база --keep        # прогон, ~12 с
python3 tools/run_model.py --scenario негативный    # сценарий
python3 tools/run_model.py --set '01_Вводные!B58=0.07' --tag ндс7
python3 tools/run_model.py --compare база ндс7      # построчная дельта
python3 -m pytest tests -q                          # 38 тестов
python3 tools/selfcheck.py                          # ловят ли тесты дефекты
python3 tools/baseline.py                           # сверка с эталоном
```

Подставлять можно только вводные (`01_Вводные`). Попытка подставить
значение в формулу отклоняется — это защита от «прогона», который на
самом деле сломал расчёт.

## Как отвечать на «что будет, если»

1. Найдите нужную вводную: `python3 tools/extract_model.py --grep "роялти"`.
2. Прогоните с подстановкой под своим тегом.
3. Сравните с базой и покажите дельту по EBITDA, деньгам, детям и школам.
4. Скажите, где результат ломается: при каком значении вводной модель
   уходит в кассовый разрыв или в убыток.

Одно число без сравнения бесполезно. Всегда давайте «было → стало → на
сколько».

## Как писать новый тест

Тест пишется тогда, когда ошибка прошла мимо существующих. Порядок такой:

1. Воспроизведите ошибку — покажите числа, которые её доказывают.
2. Напишите тест в `tests/` так, чтобы он падал на этой ошибке.
3. Убедитесь, что он **действительно падает**: добавьте дефект в
   `DEFECTS` внутри `tools/selfcheck.py` и прогоните `python3 tools/selfcheck.py`.
   Тест, который никогда не падал, ничего не проверяет.
4. Убедитесь, что на чистой модели он проходит.

Тесты сравнивают ряды помесячно, а не только итог за 60 месяцев: итог
может сойтись при разъехавшейся сезонности. Пользуйтесь `close_series` из
`tests/conftest.py` — она называет первый разошедшийся месяц.

## Границы

- Модель вы не правите: ваш результат — числа, тесты и вывод.
- Если цифры разошлись с `tests/baseline.json`, не обновляйте эталон
  молча. Сначала объясните, что именно их сдвинуло.
