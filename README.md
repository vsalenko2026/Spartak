# Финмодель «Спартак» — версия для людей

В репозитории лежит исходная финмодель V8.8, скрипт её «расшивки» и
результат — V8.9, где та же самая экономика читается без объяснений автора.

```
model/Spartak_V8_8_source.xlsx    исходник, как прислан
model/Spartak_V8_9_понятная.xlsx  результат
tools/build_user_friendly.py      скрипт: исходник -> результат
sources/                          ТЗ v6.0 и фактические отчёты, по которым сверялась модель
docs/Что_изменилось.md            подробный разбор всех правок
docs/Сверка_с_ТЗ_и_источниками.md сверка модели с ТЗ и фактом
docs/Ответы_на_разбор_09.09.2026.md ответы на вопросы Романа и Виктории
```

## Главное правило

**Ни одна формула и ни одно число в модели не изменены.**

Скрипт в конце работы сравнивает все 117 542 заполненные ячейки исходника
и результата и печатает отчёт. Сейчас он выглядит так:

```
ячеек в исходнике                : 117,542
изменённых формул/значений       : 0
удалённых ячеек                  : 0
новых ячеек вне новых листов     : 0
ИТОГ: экономика не тронута
```

Единственное исключение — четыре правки, запрошенные в разборе 09.09.2026:
лагеря выключены (`B241`) и три подписи ставок роялти привязаны к датам
`B244`/`B245`, чтобы не врать при их смене. Скрипт печатает их отдельным
списком. Всё остальное — представление, навигация и подсказки.

## Пересборка

```bash
pip install openpyxl
python3 tools/build_user_friendly.py
```

Скрипт печатает построчный список правок и в конце — отчёт сверки.
Выход `0` означает, что экономика совпала.

## Что стало понятнее — коротко

| Было | Стало |
|---|---|
| 8 ссылок навигации вели на листы, переименованные в прошлых версиях, — Excel отвечал «Ссылка недействительна» | Все 102 ссылки книги ведут в существующие листы |
| Все внутренние ссылки хранились как **внешние**, с кириллицей без URL-кодирования | Каноничный внутренний формат — не ломается вне Excel |
| «Дети к концу 12-го месяца» = 75,05 чел. показывались как **7505,0 %** | `75,1` — читается как люди |
| 44 расчётные ячейки на листе вводных выглядели как обычные вводные | Серая курсивная заливка + примечание, где лежит база для правки |
| Лист вводных — 307 строк подряд без оглавления | 16 сворачиваемых разделов, легенда и быстрый переход в закреплённой шапке |
| 46 примечаний на английском в русской модели | Переведены |
| Инструкция была вынуждена писать «зайди в B192» | 25 именованных диапазонов: `Сценарий`, `ЛагеряВключены`, `CAPEXВключён`, … |
| 65 автопроверок — простыня текста «OK / ПРОВЕРИТЬ» | Цветовая индикация + сводка «пройдено / провалено / риск плана» |
| Непонятно, с чего начинать | Лист **00_Старт**: результат, переключатели, проверки, легенда, карта листов |
| Нигде не написано, *почему* формулы такие | Лист **16а_Логика_модели**: 27 шагов от лида до денег |
| Непонятно, выполнено ли ТЗ | Лист **14а_Сверка_с_ТЗ**: 59 пунктов ТЗ v6.0 → формула → статус |
| Откуда 51 партнёр и 104 школы — неизвестно | Лист **01а_Действующая_сеть**: реестр, отток 18 школ, сверка роялти с фактом |

Подробности и обоснование каждой правки — в `docs/Что_изменилось.md`.
